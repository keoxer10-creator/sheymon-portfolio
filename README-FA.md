# وب‌سایت نمونه‌کارهای sheymon

این سایت یک وب‌سایت استاتیک است و به سرور یا دیتابیس نیاز ندارد.

## قبل از انتشار، این موارد را بررسی کن
1. ایمیل `poyapanahi.dev@gmail.com` را در `index.html` و `script.js` به ایمیل عمومی موردنظرت تغییر بده، اگر نمی‌خواهی این ایمیل نمایش داده شود.
2. توضیحات پروژه‌ها و مهارت‌ها را با وضعیت واقعی پروژه‌ها هماهنگ کن. پروژه‌ی PS5 Monitor به‌وضوح به‌عنوان ایده/مفهوم معرفی شده است.
3. آمار و ادعاهای غیرقطعی عمداً به‌شکل عمومی نوشته شده‌اند؛ تعداد پروژه یا سال تجربه‌ای که هنوز تأیید نکرده‌ای اضافه نشده است.

## انتشار رایگان در GitHub Pages
1. وارد GitHub شو و یک repository جدید بساز؛ مثلاً `sheymon-portfolio`.
2. فایل‌های داخل این پوشه (`index.html`, `styles.css`, `script.js`, پوشه‌ی `assets`) را در ریشه‌ی repository آپلود کن.
3. از بخش **Settings → Pages**، گزینه‌ی **Deploy from a branch** را انتخاب کن.
4. Branch را روی `main` و پوشه را روی `/(root)` بگذار و Save را بزن.
5. بعد از چند دقیقه، آدرس سایت در همان صفحه نمایش داده می‌شود.

## آدرس sheymon.com
ساخت این فایل‌ها به‌تنهایی دامنه‌ی `sheymon.com` را ثبت نمی‌کند. برای داشتن این آدرس باید دامنه را از یک ثبت‌کننده‌ی دامنه بخری، سپس DNS آن را به میزبان سایت (مثلاً GitHub Pages) وصل کنی. قبل از خرید، موجود بودن دامنه را بررسی کن. اگر فعلاً دامنه نمی‌خری، آدرس رایگان GitHub Pages قابل استفاده است.

## نکته فنی
فرم بک‌اند ندارد؛ دکمه‌ی تماس ایمیل را باز می‌کند و دکمه‌ی کپی ایمیل از Clipboard API استفاده می‌کند. فونت Vazirmatn از Google Fonts بارگذاری می‌شود؛ در صورت قطع اینترنت، فونت جایگزین سیستم نمایش داده می‌شود.
