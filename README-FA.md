# SHEYMON — نسخه ۸

نسخه‌ی به‌روزشده‌ی سایت شخصی پویا پناهی.

## محتویات
- `index.html` صفحه‌ی اصلی دوزبانه (فارسی/انگلیسی)
- `styles.css` طراحی شیشه‌ای، پس‌زمینه‌ی شفقی، انیمیشن‌ها و واکنش‌گرایی
- `script.js` تغییر زبان، منوی موبایل، نمایش تدریجی بخش‌ها و افکت اشاره‌گر
- `monogram.png` نشان SHEYMON
- `crypto-dashboard.svg` تصویر نمایشی رابط POYA TRADE
- `tarazino-dashboard.svg` تصویر نمایشی رابط برنامه حسابداری ترازینو
- `game-cover.svg` تصویر مفهومی STELLAR VANGUARD
- `stellar-vanguard-icon.png` آیکن بازی

## انتشار در GitHub Pages
1. ZIP را استخراج کن.
2. همه‌ی فایل‌ها را داخل ریشه‌ی مخزن GitHub قرار بده؛ خود فایل ZIP را آپلود نکن.
3. فایل‌های هم‌نام را جایگزین کن و تغییرات را Commit کن.
4. چند دقیقه بعد سایت GitHub Pages را تازه‌سازی کن.

تصاویر داشبوردهای POYA TRADE و ترازینو ماکاپ نمایشی‌اند، نه اسکرین‌شات واقعی نرم‌افزار. برای نمایش تصاویر واقعی می‌توانی بعداً اسکرین‌شات‌های خود برنامه‌ها را جایگزین کنی.


## نسخه ۹ — بازطراحی سبک و روان
- افکت‌های تمام‌صفحه و دنبال‌کننده‌ی نشانگر که باعث رندر مداوم می‌شدند حذف/غیرفعال شده‌اند.
- چرخش‌های دائمی مدارها و افکت‌های سنگین در موبایل حذف شده‌اند.
- حرکت افقی ناخواسته با محدودکردن overflow-x مهار شده است.
- افکت شیشه‌ای سبک‌تر و ظاهر الهام‌گرفته از رابط‌های مدرن iOS حفظ شده است.
- برای انتشار، فایل‌های داخل ZIP را در ریشه مخزن GitHub جایگزین کنید.
