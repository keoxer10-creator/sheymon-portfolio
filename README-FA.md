# SHEYMON — نسخه ۱۰

بازطراحی کامل سایت: مینیمال، سفید و کاراملی، با حال‌وهوای iOS و تم روشن/تاریک.

## چه چیزهایی عوض شد
- طراحی کلی از صفر بازنویسی شد؛ پالت سفید + کاراملی با تم تاریک گرم.
- دکمه‌ی تغییر تم (روشن/تاریک) بالای صفحه. در اولین بازدید تم دستگاه رعایت می‌شود و انتخاب بازدیدکننده ذخیره می‌شود.
- هدر شیشه‌ای و مات (مثل iOS)، و در موبایل نوار تب پایین صفحه به‌جای منوی همبرگری.
- لوگو بدون هیچ دایره یا پس‌زمینه‌ای، به‌تنهایی در هدر؛ نسخه‌ی تیره برای تم روشن و نسخه‌ی سفید برای تم تاریک.
- تصویر برای همه‌ی بخش‌ها: صحنه‌ی اصلی، سه تصویر پروژه، تصویر درباره من، تصویر ارتباط و آیکن ابزارها.
- با کلیک روی هر پروژه یک پنجره‌ی کشویی (Bottom Sheet) مثل iOS باز می‌شود.
- سبک و روان: بدون افکت تمام‌صفحه، بدون پیگیری نشانگر؛ حالت شیشه‌ای فقط روی چند عنصر کوچک ثابت.
- آیکن سایت، آیکن اپل و تصویر پیش‌نمایش اشتراک‌گذاری (og-image) اضافه شد.

## فایل‌ها
- `index.html` صفحه‌ی اصلی دوزبانه (فارسی/انگلیسی)
- `styles.css` طراحی، تم روشن/تاریک، واکنش‌گرایی
- `script.js` زبان، تم، منوی فعال، پنجره‌ی پروژه
- `monogram.png` لوگوی سفید (برای تم تاریک)  |  `monogram-dark.png` لوگوی تیره (برای تم روشن)
- `hero-scene.svg`، `project-trade.svg`، `project-tarazino.svg`، `project-stellar.svg`، `about-workspace.svg`، `contact-scene.svg` تصاویر سایت
- `stellar-vanguard-icon.png` آیکن بازی
- `favicon.png`، `apple-touch-icon.png`، `icon-192.png`، `og-image.jpg`

## انتشار در GitHub Pages
1. ZIP را استخراج کن.
2. همه‌ی فایل‌ها را داخل ریشه‌ی مخزن قرار بده (خود ZIP را آپلود نکن).
3. فایل‌های هم‌نام را جایگزین کن و Commit بزن.
4. فایل‌های قدیمی `crypto-dashboard.svg`، `tarazino-dashboard.svg` و `game-cover.svg` دیگر استفاده نمی‌شوند و می‌توانی حذفشان کنی.

تصاویر پروژه‌ها نمایشی (ماکاپ) هستند، نه اسکرین‌شات واقعی. هر وقت خواستی، اسکرین‌شات‌های واقعی برنامه‌ها را با همان نام فایل‌ها جایگزین کن.
