# SHEYMON Portfolio — نسخه ۶

پورتفولیوی بازطراحی‌شده با تم شیشه‌ای رنگی، هاله‌های نور شناور، انیمیشن‌های نرم و نسخه فارسی/انگلیسی.

## انتشار در GitHub Pages
1. فایل ZIP را استخراج کنید.
2. همه فایل‌های داخل این پوشه را در ریشه مخزن `sheymon-portfolio` آپلود کنید؛ خود ZIP را آپلود نکنید.
3. فایل‌های هم‌نام را جایگزین کنید و `Commit changes` را بزنید.
4. چند دقیقه بعد سایت را با همان لینک قبلی باز کنید.

## فایل‌ها
- `index.html` ساختار و محتوای سایت
- `styles.css` طراحی واکنش‌گرا، شیشه‌ای و انیمیشن‌ها
- `script.js` تغییر زبان، منوی موبایل، ورود تدریجی و افکت کارت‌ها
- `monogram.png` نشان SHEYMON
- `crypto-dashboard.svg` تصویر نمایشی پروژه POYA TRADE
- `tarazino-dashboard.svg` تصویر نمایشی پروژه ترازینو
- `game-cover.svg` تصویر مفهومی Stellar Vanguard
- `stellar-vanguard-icon.png` آیکون استخراج‌شده از APK ارسالی

تصاویر داشبورد پروژه‌ها فعلاً تصاویر نمایشی هستند؛ برای نمایش محیط واقعی برنامه‌ها، بعداً اسکرین‌شات‌های خود برنامه‌ها را جایگزین کنید.


### تصاویر پروژه‌ها
تصویر POYA TRADE و ترازینو در این بسته، موکاپ رابط کاربری برای معرفی پروژه‌هاست، نه اسکرین‌شات ثبت‌شده از اجرای برنامه. فایل اجرایی POYA TRADE به‌تنهایی تصویر واقعی از پنجره‌های برنامه در اختیار نمی‌گذارد. برای نمایش دقیق UI، از داخل برنامه اسکرین‌شات بگیرید و فایل تصویری را جایگزین `crypto-dashboard.svg` کنید (یا نام فایل تصویر را در `index.html` تغییر دهید). آیکون Stellar Vanguard از فایل برنامه استخراج‌شده‌ی موجود در بسته قبلی استفاده می‌شود.
